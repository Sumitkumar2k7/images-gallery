# 📸 React Image Gallery (Pexels API)

A modern, fast, and responsive image gallery built using **React**, **Tailwind CSS**, and the **Pexels API**.  
Users can search for high-quality images, browse unlimited photos, and download any image with a single click.

---

## 🚀 Features

- 🔍 **Search Images** by keyword  
- 📄 **Load More Pagination** for infinite scrolling  
- ⚡ **Fast & Responsive UI**  
- ⏳ **Smooth loading animations**  
- 📥 **One-click image download**  
- 🎨 **Clean & modern layout using Tailwind CSS**  
- 🔔 **Toast notifications** for errors & status updates  

---

## 🛠️ Tech Stack

- **React.js**  
- **Tailwind CSS**  
- **Axios**  
- **Pexels API**  
- **React Toastify**  
- **Remix Icons**
